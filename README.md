# audioguide-audit — аудиторский срез проекта «Island Guide»

Этот репозиторий — **зеркало-срез основного проекта**
[riskprofitLLC/audioguide](https://github.com/riskprofitLLC/audioguide),
предназначенное для внешнего аудита кода. Обновляется автоматически
скриптом `tool/push_audit.sh` **после каждого пуша в `main`**
основного репозитория; вручную сюда ничего не коммитится.

**История не ведётся**: репозиторий всегда состоит из ОДНОГО коммита
«Аудит-срез: \<sha\> \<сообщение\>» — истории изменений здесь не нужно,
она живёт в основном репозитории (sha источника указан в сообщении).
**Ограничение размера**: совокупный размер всех файлов среза — не более
~2,6 МБ (лимит проверяется скриптом перед пушем; текущий размер ~2,0 МБ
после ужима на ~20%: удалены `prompts/`, `android/`, часть `tool/` и
самые объёмные дублирующие тесты).

## Состав среза (только то, что нужно для проверки кода)

| Путь | Что это |
|---|---|
| `lib/` | Весь Dart-код приложения (offline-first Flutter-гид) |
| `test/` | Тесты, кроме дублирующих layout/admin и файлов >7 КБ каждый |
| `tool/` | Базовые инструменты проверки: `verify.sh`, `check_assets.py`, `push_audit.sh` |
| `pubspec.yaml`, `analysis_options.yaml` | Зависимости и линт-правила |

## Чего здесь НЕТ (сознательно)

- `content/` — офлайн-контент (POI, аудио, фото, pmtiles-карты, сотни МБ).
- `assets/` — медиа-иконки.
- `prompts/` — устаревшая спецификация и история замечаний.
- `web/`, `android/` — платформенные конфиги и хуки (не код приложения).
- `AGENTS.md` — правила для агентов-разработчиков, не описание кода;
  полные инварианты проекта — в основном репозитории.
- Контент-генераторы `tool/` (`generate_audio.py`, `sync_texts.py`,
  `build_region_map.py` и пр.) — без `content/` не запускаемы;
  это производство данных, не код приложения.
- Дублирующие widget/layout-тесты и самые объёмные тесты (>7 КБ) —
  ужаты для лимита размера без потери ценности аудита.
- A/B-реликты `tool/*.wav|*.mp3` и разовые скрипты-заготовки.
- `web/vendor/` — вендорные сборки MapLibre GL JS / pmtiles.
- `build/`, `.dart_tool/`, платформенные песочницы (ios/linux/macos/windows).

## Как читать код

- Архитектура: Clean Architecture, feature-first
  (`lib/features/<feature>/{domain,data,presentation,services}`).
- Карта — одна библиотека `_MapWidgetState` в `part`-файлах
  (`map_widget.dart` + `map_camera/layers/overlays/tracking/taps/…`).
- Дизайн-система «Ликийский дневник»: `lib/app/theme.dart` +
  `lib/app/design_tokens.dart` (Prata/Manrope, бумага `#F7F2E7`,
  чернила `#16333C`, бирюза `#19617B`, сигнал `#E85D3F`).
- Правила и инварианты каждого «прохода» разработки — в `AGENTS.md`
  основного репозитория.

## Обновление

Срез обновляется только скриптом из основного репозитория:

```bash
bash tool/push_audit.sh
```
